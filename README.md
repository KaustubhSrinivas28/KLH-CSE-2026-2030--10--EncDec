# KLH-CSE-2026-2030--10--EncDec
This project designs a 4 bit symmetric key encryption and decryption unit in Logisim using combinational logic. A 4 bit plaintext is XORed with a 4 bit key to create ciphertext. Applying same key again recovers plaintext. Four comparators verify the result. The design uses 8 XOR gates and 4 comparators, with all 16 inputs tested successfully.
